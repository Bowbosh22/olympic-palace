# Olympic Palace — démo de refonte

Démo de site web pour l'Olympic Palace Hôtel (Brazzaville), proposée par l'Atelier KPM.

- Fichier unique : `index.html` (photos et styles inclus, aucune dépendance à installer)
- Les polices sont chargées depuis Google Fonts
- Les formulaires ouvrent WhatsApp avec un message prérempli

Les photos de l'hôtel sont provisoires, à remplacer par des originaux HD.
